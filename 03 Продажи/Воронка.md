# Воронка продаж

## TriWord Office
- Платящих пользователей пока нет. Оплачивали сами, чтобы проверить работу системы.
- Попробовали около 60 человек: показывали лично, канал продаж ещё не запускали.
- Этапы: контент (Reels / статья «как сделать в Excel/Word» / урок) → @triword_bot или сайт → скачал → пробные 7 дней + серия сообщений → оплатил подписку.
- Петля роста: акция в панели «приведи коллегу — месяц бесплатно обоим» → новые установки.
- Организации: бот («для организации») → демо Руслана → пробный на отдел → счёт.
→ [[Каналы привлечения]]

## TriWord School
1. Контакт с администрацией (директор, руководитель корпуса)
2. Аудит шаблонной документации: где применить ИИ ← **мы здесь** ([[Школа 2094]])
3. Пилот в школе
4. Договор. На первых этапах, скорее всего, прямой, дальше закупка через тендер по 44-ФЗ. Нужно выйти на специалиста по закупкам внутри школы.
5. Масштабирование → цель 28 школ к концу 2027 ([[Цели на год]])
