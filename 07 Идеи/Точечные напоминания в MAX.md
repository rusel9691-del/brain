# Точечные напоминания родителям в MAX

**Суть:** классный (или система по правилу) отправляет напоминание родителю не «всем классом», а по конкретному ученику и конкретному документу: «у Тимора не сдано согласие на самоуход, срок — 15.10». Из карточки ученика / реестра / входящих — одна кнопка «Напомнить в MAX».

## Почему может сработать
- Основная причина несданного — не отказ, а «забыли / не увидели» (по опроснику 2094: самоуход, подвоз, анкеты).
- Массовая рассылка читается как спам; личное сообщение с фамилией ребёнка и сроком — читается всегда.
- Классный экономит время: не надо писать вручную в чат и потом сверять «кто ответил».
- Даёт метрику: отправлено / прочитано / сдано — видно, где реально застревает родитель.

## Риски и сомнения
- MAX остаётся только каналом напоминания: заявление принимается в кабинете, иначе снова получим «родитель написал в чат» и потерю оригинала.
- Нужен антиспам-лимит (например не чаще 1 напоминания в 3 дня на документ) и шаблоны, чтобы не превратилось в переписку.
- Согласие родителя на получение сообщений в MAX + 152-ФЗ: не отправлять лишние ПДн в текст сообщения.
- Зависимость от API MAX: если закрытого API нет — на первом этапе руками ссылкой.

## Первый шаг
1. Проверить, есть ли у MAX бот-API для адресных сообщений (или только чат-боты/каналы).
2. Сделать 3 шаблона: «не сдано», «нужна правка», «готово, спасибо».
3. В прототипе — кнопка «Напомнить в MAX» на карточке ученика и в реестре.
