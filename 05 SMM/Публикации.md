# Публикации

Очередь постов TriWord. Отсюда SMM-агент Hermes берёт, что согласовать и выложить.

**Как работает:** 09:00 — Hermes присылает в Telegram публикации на сегодня → Руслан отвечает «ок / правки / перенос». Без «ок» ничего не публикуется. 19:00 — напоминание, если не отмечено. Воскресенье 20:00 — отчёт по публикациям и охватам.

**Материалы:** Яндекс Диск, папка «TriWord посты» — https://disk.yandex.ru/d/4OnovKT8U-H9vw. В колонку «Материал» пишем имя файла из этой папки.

**Статусы:** `черновик` → `готово` → `согласовано` → `опубликовано` (+ `перенос`, `отменено`).
**Дата:** строго `ГГГГ-ММ-ДД`, одна строка = одна площадка (дубль Reels в Shorts — отдельной строкой).
