# Контент-план

**Задача:** стать небольшой медиамашиной — держать стабильный темп.

| Формат | Где | Частота |
|---|---|---|
| Reels | Instagram + дубль в YouTube Shorts | 1 в день |
| Статья | Дзен + дубль в Telegram | раз в 2 дня |
| Большой ролик | YouTube | 1 в неделю |

**Нагрузка:** ~30 Reels, ~15 статей, ~4 ролика в месяц.

## Статьи «сначала вручную — потом с ИИ» (TriWord Office)
Статьи-инструкции «как сделать X в Excel / Word / PowerPoint»: сначала вручную по шагам, затем — то же одной фразой в TriWord, призыв скачать. Публикуем на **Дзен + блог triword.ru**. Одна тема = статья + Reels + урок YouTube.
- [ ] Список тем и график — делаем в отдельном окне → [[Каналы привлечения]]

## Кто делает
- **Руслан** — главное лицо и автор.
- **Партнёры** — при необходимости.
- **Hermes** — помогает: сценарии Reels, статьи (через «Статейник»), шорты. Как именно — обсудим позже (см. «Отложенные задачи» на [[Главная]]).

## Инструменты контента
- **Статейник** — система Hermes для SEO-статей под ключ (Дзен + Telegram).
- **Telegram Mini App TriWord** — приложение бренда, точка входа из Telegram. → [[TriWord]]
